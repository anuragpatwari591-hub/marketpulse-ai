# MarketPulse AI — Frontend

React + TypeScript + Vite + Tailwind terminal UI. See the [repository root README](../README.md) for the full project overview, and [DEVELOPMENT.md](../DEVELOPMENT.md) for the local dev workflow.

```bash
npm install
npm run dev      # http://localhost:3000, proxies /api and /ws to :8000
npm run test     # vitest
npm run build    # tsc -b && vite build
```
